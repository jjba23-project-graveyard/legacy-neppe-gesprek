#+title: Neppe Gesprek
#+options: toc:nil num:nil

🚧 work in progress

Neppe Gesprek (Dutch for *Fake Conversation*) allows film and television makers to stage scenes where chat software is being used.

This is free software (free as in freedom), licensed under the GNU General Public License v3 or newer.

** Key features

- *Fully Customizable:* Hack the behavior and content of each UI element with Scheme code.
- *Scriptable:* Control the conversation flow using Scheme snippets.
- *Themable*: Allows many theming options, so as to portray different characters in a scene easily.
- *Multiple Languages:* Supports any language you may want to use and writing system.
- *Cross-platform:* Runs anywhere that Guile Scheme can run, and exposes web endpoints, and is thus accessible from computers, phones, etc.
- *Free Software*: Contribute to its development or extend it with your own custom features.
